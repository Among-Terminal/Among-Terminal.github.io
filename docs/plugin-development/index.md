# Plugin development

Plugins are separate programs that anyone can write to add status information
or notifications to Among Terminal.

The [among-plugin-template repository](https://github.com/Among-Terminal/among-plugin-template)
contains the plugin author guide and API reference.

When your plugin is ready, submit a pull request to add it to
[awesome-among-terminal](https://github.com/Among-Terminal/awesome-among-terminal).
